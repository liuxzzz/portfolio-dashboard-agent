# PRD v0.1

## 产品目标

每天自动获取用户在同花顺投资账本中的最新账户和持仓，保存历史快照，并生成适合电脑与手机查看的个人看板。

第一版帮助用户回答：

1. 我现在持有什么？
2. 资金集中在哪里？
3. 相对上一个有效快照发生了什么变化？
4. 当前看到的数据是否真的足够新？

## MVP

- 单用户、多账户。
- 每个交易日收盘后采集一次。
- 总资产、现金、股票市值、仓位和持仓数量。
- 个股仓位、集中度、行业分布。
- 新增、加仓、减仓和清仓变化。
- 采集时间与源同步时间。
- 登录失效、数据过旧和采集失败提醒。

## 非目标

- 不自动下单。
- 不提供收益承诺。
- 不把分析表达为确定性投资建议。
- 不在第一阶段面向公众开放。

## 成功标准

- 连续 14 个交易日采集成功率不低于 90%。
- 关键账户金额和持仓数量与官方导出抽查一致。
- 数据过旧识别率为 100%。
- 日志和业务数据库中不出现登录凭证。
